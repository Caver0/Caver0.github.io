Particle Swarm Optimization (PSO Lab)

Entorno experimental y algorítmico diseñado para analizar y comparar la evaluación de funciones objetivo mediante múltiples paradigmas de concurrencia y paralelismo. Permite aislar y contrastar de manera reproducible modos secuenciales, multihilo, multiproceso, computación asíncrona (asyncio para entornos I/O-bound) y vectorización nativa en bloques con NumPy. Incluye pipelines analíticos que generan gráficas de convergencia y análisis paramétrico frente a baselines de la industria.

Python NumPy Asyncio Multiprocessing Matplotlib Pytest

Proyecto Servidores Web — GastroMatch

Arquitectura de aplicación web contenerizada orientada a la toma de decisiones grupales en tiempo real (votación de restaurantes y gestión de salas).
